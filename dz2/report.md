# Домашнее задание 2

## Задание

Реализовать паттерны Strategy и Decorator с использованием `std::function`.

## Strategy

В `strategy/main.cpp` реализованы разные способы вычисления итоговой цены товара:

- без скидки;
- скидка 10%;
- скидка 20%.

Для хранения выбранной стратегии используется:

`std::function<double(double)>`

Все стратегии имеют одинаковую сигнатуру и могут взаимозаменяться.

Функция `CalculatePrice` получает стратегию как аргумент и вызывает её. Она не знает, какой именно алгоритм вычисления цены используется.

Таким образом, паттерн Strategy позволяет менять алгоритм вычисления результата, не изменяя код, который этим алгоритмом пользуется.

## Decorator

В `decorator/main.cpp` реализована функциональная версия паттерна Decorator.

Общий интерфейс компонента задаётся типом:

`std::function<std::string(const std::string&)>`

Базовый компонент `PlainText` возвращает исходный текст без изменений.

Каждый конкретный декоратор принимает существующий компонент и возвращает
новый компонент того же типа:

- `BracketsDecorator` добавляет квадратные скобки;
- `StarsDecorator` добавляет звёздочки;
- `QuotesDecorator` добавляет кавычки.

Также используется тип:

`std::function<TextFunction(const TextFunction&)>`

Он описывает сам декоратор: функцию, которая принимает компонент
и возвращает новый компонент.

Например, `StarsDecorator` сначала вызывает предыдущий компонент,
а затем добавляет звёздочки вокруг полученного результата.

Благодаря тому, что после декорирования получается объект того же типа
`TextFunction`, декораторы можно последовательно накладывать друг на друга.

Для текста `hello` последовательность

`brackets -> stars -> quotes`

даёт:

`"*[hello]*"`

Роли паттерна:

- `TextFunction` — общий интерфейс компонента;
- `PlainText` — базовый компонент;
- `BracketsDecorator`, `StarsDecorator`, `QuotesDecorator` — конкретные декораторы.

Decorator добавляет новое поведение вокруг существующего компонента,
не изменяя сам компонент.

## std::function

`std::function` позволяет хранить и передавать вызываемые объекты с заданной сигнатурой.

В Strategy он используется для хранения выбранного алгоритма.

В Decorator он позволяет передавать предыдущую функцию следующему декоратору и строить цепочку обёрток.

## Разница между паттернами

Strategy заменяет один алгоритм другим.

Decorator сохраняет существующее поведение и добавляет вокруг него новое.
